# IRON VANGUARD — 坦克保衛戰

## 多場景輪替

六個波次自動輪替六張場景：經典戰場、河川要塞、鋼鐵迷宮、沙洲運河（水域多）、密林突擊（草叢多）、最終防線（鋼牆多）。進入下一波時會載入新地形並清除上一波的子彈、道具與特效；分數、生命與玩家強化狀態會保留。波次提示畫面會顯示目前場景名稱。

可用 `python test/multi_scene_test.py` 單獨驗證場景輪替。

**線上遊玩**：<https://game-tank.tingyudeco.com/>　**遊戲攻略**：<https://game-tank.tingyudeco.com/guide.html>

2D 俯視角坦克射擊遊戲。玩家操控坦克在迷宮化競技場中保護基地，擊退 6 波敵方坦克進攻。
純 HTML5 Canvas + 原生 JavaScript 打造：無框架、無遊戲引擎、無外部圖片與音效檔、無 CDN，可完全離線執行。

## 操作方式

| 按鍵 | 功能 |
|------|------|
| W / ↑ | 向上移動 |
| S / ↓ | 向下移動 |
| A / ← | 向左移動 |
| D / → | 向右移動 |
| Space | 發射砲彈（長按連發，有冷卻；同時最多 2 顆） |
| P | 暫停 / 繼續 |
| M | 音效總開關（含音樂） |
| B | 背景音樂開關 |
| R | 遊戲結束（勝利或失敗）後重新開始 |
| Enter / Space | 開始畫面按下開始遊戲 |

手機／平板自動切換觸控操作：左半屏浮動虛擬搖桿、右下 FIRE 鈕長按連射、右上暫停鈕。

## 啟動方式

任選其一：

1. **直接開啟**：雙擊 `index.html`（採用 classic script，`file://` 協定可直接執行）。
2. **本機伺服器**（建議）：
   ```
   cd Game-tank
   python -m http.server 8777
   ```
   然後開啟 <http://127.0.0.1:8777/>。

## 遊戲規則

- 保護底部中央的**基地**（金星圖徽）：被任何砲彈擊中即摧毀，摧毀＝遊戲失敗。
- 基地周圍有可破壞磚牆環，敵人會嘗試打穿它。
- 玩家有 3 條生命；被擊中後於出生點重生，重生附 3 秒無敵（閃爍＋護盾圈）。
- 清除當前波次所有敵人後進入下一波（間隔顯示 2.5 秒波次提示，期間敵人不攻擊）。
- 撐過全部 **6 波**即勝利，每一波在不同的地圖場景作戰。

### 地形

| 地形 | 坦克 | 砲彈 | 備註 |
|------|------|------|------|
| 空地 | 通過 | 通過 | |
| 磚牆 | 阻擋 | 阻擋 | 可破壞；每格 2 段耐久，破口約兩格寬 |
| 鋼牆 | 阻擋 | 阻擋 | 不可被普通砲彈摧毀 |
| 水面 | 阻擋 | 通過 | 波紋動畫 |
| 草叢 | 通過 | 通過 | 繪於坦克上方，部分遮擋 |

### 敵人類型

| 類型 | 顏色 | 速度 | 耐久 | 分數 | 特徵 |
|------|------|------|------|------|------|
| 普通型 | 灰 | 中 | 1 | 100 | 隨機巡邏並向基地推進 |
| 快速型 | 青 | 快 | 1 | 150 | 車體略小、轉向頻繁 |
| 重裝型 | 紅 | 慢 | 4 | 300 | 車體厚重、頭頂顯示血量格 |

完成波次另有加分（300 × 波數）。

### 寶物

敵人被擊毀時 25% 機率掉落，10 秒後消失（最後 3 秒閃爍提醒），玩家開過去即撿取：

| 寶物 | 圖示 | 掉落權重 | 效果 |
|------|------|---------|------|
| 醫療補給 | 綠十字 | 2 | +1 生命（上限 5；滿命時改給 500 分） |
| 加速 | 青色雙箭頭 | 3 | 8 秒內移速 ×1.45（車尾顯示氣流特效） |
| 護盾 | 藍色盾牌 | 3 | 6 秒無敵（與重生無敵取較長者，不疊加） |
| 強化砲彈 | 橘色彈頭 | 2 | 15 秒內砲彈可破鋼牆、磚牆一發全毀（彈體變橘） |
| 鏟子 | 鏟子 | 2 | 基地磚牆環變鋼牆 15 秒（含修復缺口），到期還原全新磚牆 |
| 星星 | 金星 | 2 | 火力升級：一級加射速與彈速、二級 +1 同屏彈數（滿級改給 500 分） |
| 炸彈 | 紅色炸彈 | 1（最稀有） | 場上敵人全數即毀並照常計分 |
| 冰凍 | 冰藍雪花 | 2 | 8 秒內所有敵人原地凍結（不移動不開火），已飛出的砲彈照常 |
| 機關槍 | 桃紅三連彈 | 2 | 8 秒內射擊冷卻 ×0.45（與星星射速疊乘） |
| 金幣 | 金色銅錢 | 3 | 即時 +500 分 |

限時 buff（加速/強化砲彈/機關槍）與星星等級在死亡重生後清除；
HUD 中段顯示進行中的 buff（★ 等級、PW/SP/MG/FT/FZ 剩餘秒數）。
鏟子加固/還原時被坦克壓住的格子會跳過，避免把坦克封進牆裡。

### 敵人 AI

有限狀態決策（非機器學習）：方向權重（偏向基地、偶爾追玩家、避免回頭）＋
與玩家/基地同軸且視線無阻擋時高機率轉向射擊＋面對磚牆時偶爾射擊開路＋
位移監測卡住偵測（卡住強制換向並射牆）。決策有計時器，不會逐幀抖動。

- 視窗等比縮放不影響碰撞（邏輯座標固定 960x720）

## 測試

```
python -m http.server 8777          # 先起伺服器
python test/e2e_test.py             # 43 項驗收測試
python test/multi_scene_test.py     # 場景輪替回歸測試
python test/powerup_variety_test.py # 寶物回歸測試
```

最近一次結果：e2e 43/43 通過；soak 60 秒 heap 零成長、console 零錯誤；FPS ≈ 61。
（需要 `pip install playwright` 並安裝 chromium。）

## 已知限制

- 敵人 AI 為權重式移動，不做全域路徑規劃（A*），偶爾會繞路——屬刻意取捨，行為更接近經典街機。
- 玩家砲彈同樣會摧毀自己的基地（經典規則），請小心走火。
- 音量固定（master gain 0.25），僅提供開/關。
- 單人遊玩、無手把支援。
